# grocery-api

Товары для рецептов приложения «Ладно»: Перекрёсток, Пятёрочка и Магнит.

Выгрузка 27 октября 2026 года: **343 рецепта, 29 ингредиентов (28 покупаемых), 608 товаров с составом**. У 454 товаров одновременно есть состав, цена и пригодные для расчёта КБЖУ. 19 карточек без подтверждённого состава сохранены отдельно. У каждого рецепта есть товары на все покупаемые ингредиенты хотя бы в одной сети.

Данные и код работают отдельно от приложения, из которого прочитаны рецепты. Источник рецептов — `GET http://127.0.0.1:18081/api/v1/recipes/`, 15 страниц; исходные ID, количества, единицы измерения и порции сохранены.

## Запуск API

```sh
docker compose -p grocery-api -f grocery_recipe_collector/compose.catalog.yml up -d --build
curl http://127.0.0.1:18082/health
```

Альтернатива без Docker, Python 3.10+ без дополнительных библиотек:

```sh
python3 grocery_recipe_collector/catalog_service.py \
  --data grocery_recipe_collector/data/ladno_2026-10-27/catalog.json.gz
```

API доступен по `http://127.0.0.1:18082/`. Описание запросов и смысла полей: [API.md](grocery_recipe_collector/API.md).

## Данные

- [catalog.json.gz](grocery_recipe_collector/data/ladno_2026-10-27/catalog.json.gz) — полный JSON в gzip: рецепты, ингредиенты, товары, кандидаты, связи и покрытие.
- [summary.json](grocery_recipe_collector/data/ladno_2026-10-27/summary.json) — фактические счётчики и пропуски.
- [coverage.json](grocery_recipe_collector/data/ladno_2026-10-27/coverage.json) — 84 сочетания «ингредиент × сеть».
- [catalog.py](grocery_recipe_collector/catalog.py) — выгрузка API рецептов, разбор сохранённых официальных карточек, JSON/JSONL и SQLite.

Распаковать без сторонних зависимостей:

```sh
python3 -c 'import gzip,pathlib; p=pathlib.Path("grocery_recipe_collector/data/ladno_2026-10-27/catalog.json.gz"); p.with_suffix("").write_bytes(gzip.decompress(p.read_bytes()))'
```

## Что подтверждено

Состав, КБЖУ и цена извлекаются из одной конкретной карточки того же артикула и сети. Составы между магазинами и упаковками не переносятся. Карточки без состава доступны только как `candidates`. Рецептурные справочные КБЖУ приложения хранятся отдельно от этикеток товаров.

Прямые открытия из Camoufox блокировались X5; Магнит просил выбрать магазин, а повторные открытия карточек вернули пустые страницы. Для сбора использован публичный индекс официальных карточек. Поэтому все цены имеют `price_freshness: indexed_unverified`, `price_observed_at: null`, а регион не приписан автоматически. Цена и наличие по конкретному адресу требуют обновления в официальной сессии магазина. Это собранные варианты, а не подтверждение полного ассортимента.

Остались два сочетания без готового предложения: консервированный нут в Пятёрочке и бананы с опубликованным составом в Магните. У ряда товаров не опубликованы отдельные КБЖУ, цены или масса без жидкости. Эти пропуски доступны через API и `coverage.json`.

Ранний пример супа и `seed_offers.json` сохранены как исторические файлы; новый каталог собирается независимо от них.
