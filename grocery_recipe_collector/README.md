# Сбор продуктов по рецепту: Перекрёсток, Пятёрочка, Магнит

Для выгрузки всех рецептов «Ладно» и API нового каталога см. [основную документацию](../README.md) и [API.md](API.md). Этот файл описывает ранний браузерный сборщик одного рецепта; новый каталог не использует исторический `seed_offers.json` как источник подтверждённых составов.

Небольшой переносимый комплект для поиска товаров, подходящих ингредиентам рецепта, на сайтах трёх сетей. Результат — JSON с нормализованными полями, а также CSV для ручной проверки.

## Статус адаптеров

В текущем комплекте три адаптера устроены по-разному:

- **Пятёрочка** — открытый каталог и карточки товара; сборщик использует поисковые страницы и Camoufox.
- **Магнит** — открытый каталог и карточки товара; сборщик использует поисковые страницы и Camoufox.
- **Перекрёсток** — у пользователя сайт блокировал IP контейнера Camoufox защитой. Адаптер сообщает о блокировке, если она повторится. Не добавляйте обход аутентификации/защиты; используйте доступную пользователю официальную сессию/маршрут или вручную передайте карточки в `--seed`.

Результаты поиска не гарантируют полный ассортимент: полнота зависит от выдачи магазина, региона, наличия и доступности страниц. Каждый товар включает URL и время сбора.

**Состав обязателен для записи в `offers`.** Сборщик открывает карточку кандидата и пытается извлечь раздел «Состав». Если состав не опубликован или не найден, товар исключается из `offers` и попадает в `rejected_products` с причиной. Приложения должны использовать только `offers` как готовые товарные записи; пустой состав не считается успешно собранным товаром.

## Быстрый старт

Python 3.10+ и пакеты из `requirements.txt`:

```sh
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
playwright install firefox
python collect.py --recipe recipe.example.json --out results.json --region "Москва"
```

Чтобы прогнать браузер в уже запущенном Camoufox Docker, смонтируйте каталог проекта и выполните команду внутри контейнера с установленными `camoufox` и `playwright`:

```sh
docker exec -i camoufox-browser python /workspace/collect.py \
  --recipe /workspace/recipe.example.json --out /workspace/results.json --region "Москва"
```

Пути `/workspace` в примере задаются volume mount при запуске контейнера. Сборщик не меняет существующий контейнер и не пытается управлять корзиной/заказом.

## Вход рецепта

См. `recipe.example.json`. Количества относятся к съедобной части. Поддерживаются `g`, `kg`, `ml`, `l`, `pcs`; для каждого ингредиента можно передать поисковые фразы и необязательные исключения. Необязательное поле `stores` ограничивает сети.

## Результат

Каждая запись в `results.json -> offers` соответствует `schemas/offer.schema.json`; поле `ingredients_text` обязательно и должно содержать непустой извлечённый состав. Товары без состава находятся отдельно в `rejected_products` и не должны отображаться/использоваться как готовые предложения. Денежные значения — числа в рублях. КЖБУ берутся с карточки продукта; неизвестные значения остаются `null`. `recipe_cost_estimate` не смешивается с ценой упаковки.

Сырые названия и состав сохраняются рядом с нормализованными полями. Не приписывайте товар рецептурному ингредиенту автоматически при низкой уверенности: оставляйте `match_confidence` и `match_notes`.

## Использование как сервиса

Сборщик можно импортировать:

```python
from collect import collect_recipe
offers = collect_recipe(recipe, region="Москва", stores=["pyaterochka", "magnit"])
```

Для приложения лучше запускать его как отдельный job по расписанию/за запрос и сохранять JSON с `collected_at`, чтобы интерфейсу не приходилось парсить сайт.

## Данные из текущего чата

- `recipe.example.json` — рецепт супа из тыквы и картофеля на 3 порции.
- `seed_offers.json` — набор из 163 предложений с подтверждённым непустым составом и ссылкой `composition_source_url`; ещё 3 кандидата находятся отдельно с `composition_status: not_found` и не предназначены для использования как готовые предложения. Данные собраны для этого рецепта и не гарантируют полный ассортимент сети или актуальность цены вне региона/времени сбора.
